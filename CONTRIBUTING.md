# Contributing

Thank you for contributing to the WP5 framework. The short version:

1. **Pick or create a node.** One file = one principle, guideline or piece of practical guidance. Copy [templates/node-template.md](templates/node-template.md) into the right folder under `framework/`.
2. **Write and cite.** Fill in the front matter, write the text, list your `sources` and link the node upwards (`realises`, `derives_from`, `supports`).
3. **Open a pull request.** Use a branch, describe what you changed, and tick the checklist in the PR template. The validator runs automatically.
4. **Review.** At least one reviewer from the task that owns the folder approves. Cross-task links are checked by the other task as well.
5. **Merge.** A repository maintainer merges when the review is done.

Details:

- [Contribute directly with Git and Markdown](docs/guides/02-contribute-with-git.md), including how to do it in the GitHub web interface without installing anything.
- [Contribute with an AI assistant](docs/guides/03-contribute-with-ai.md)
- [How to write a node](docs/guides/04-node-format.md)
- [Review and verification](docs/guides/05-review-and-verification.md)

Everything in the repository is written in **English**.
