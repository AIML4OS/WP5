**Short description:** The results of the model can be identically reproduced.

Reproducibility is the ability to achieve identical results when using the same data and the same code to learn, choose and apply a model. In practice this is achieved by versioning, documenting and archiving data, code and libraries, preferably as a standard procedure for all use cases. It ensures trust in official statistics and the auditability of administrative activities. The practical challenge often lies in recreating the exact conditions at any given time.
