Model registries support traceability by storing information about model versions, intended use, validation status, deployment history and lifecycle decisions (paper, Section 2). They are named as one of the mechanisms for governability of a fit-for-purpose architecture (Section 5), and as part of the stronger lifecycle management needed when a model is embedded in a recurring production process (Section 7).
